## Regra de consistência

- O arquivo deste índice organiza o planejamento.
- Cada tema deve ser detalhado somente no arquivo indicado.
- Decisões importantes devem conter data, responsável e motivo.
- Mudanças que afetarem outros temas devem ser refletidas nos arquivos relacionados.
